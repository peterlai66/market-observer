# AI_WORKFLOW

## New Chat Workflow
1. 使用者上傳 repo zip
2. 使用者要求依照 `MO_START.md` 接續開發
3. AI 先讀 `MO_START.md`
4. AI 再讀 `docs/PROJECT.md`、`docs/AI_MEMORY.md`、`docs/NEXT_TASK.md`
5. 理解後才開始改程式

## Handoff Workflow
1. 使用者輸入 `Handoff`
2. AI 整理對話中尚未寫回 repo 的內容
3. AI 更新相關文件與結構
4. AI 產出新的 handoff zip
5. 使用者下載後在新聊天室上傳
