# Repo Map Tool Specification

Planned CLI:
mo repo-map

Purpose:
Scan repository and generate docs/repository_live_map.md

Include directories:
- src
- scripts
- docs
- migrations
- developer

Ignore:
- node_modules
- .updates
- .git
- dist

Note:
This file is a specification only. The actual tool should be implemented later in a verifiable environment.
